Witness

Independent evidence classes

A claim is weak if every supporting source is the same kind of thing. Noeti asks for independent witness classes — and can run checks across independent compute nodes, not only one model endpoint.

  • Primary record Court filings, registries, official documents.
  • Documentary evidence Leaks, contracts, correspondence, archives.
  • Timeline consistency Dates and sequences that hold under scrutiny.
  • Network compute Independent nodes agreeing on the same check — multi-witness, not one cloud brain.
