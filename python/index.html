The problem

Two broken models holding AI back

Centralized clouds concentrate power and cost. Blockchains burn energy on useless hashes. Neither model scales open AI for everyone.

☁

Centralized AI is a bottleneck

A handful of providers control inference. Costs rise, access narrows, and millions of idle GPUs worldwide contribute nothing to the ecosystem.

⛏

Crypto mining wastes compute

Proof-of-Work burns electricity on SHA-256 hashes with zero external value. That same hardware could run real AI — but today's chains don't reward it.

Our solution

Useful work replaces wasteful mining

Noetis coordinates a mesh of independent nodes that run real LLM inference locally. Consensus verifies outputs. Contributors earn MLC tokens for correct, fast responses.

⚡

Proof-of-Inference

Each block records a verified AI task — not a meaningless hash puzzle. Security comes from redundant inference and majority consensus on outputs.

🌐

Open compute mesh

Laptops, desktops, and servers join via simple worker software. No single model host. Compute stays distributed, private, and scalable.

How it works

From prompt to reward in four steps

A working prototype demonstrates the full loop — live on a local test network today.

01

User submits a prompt

A client sends a query to the network coordinator over a lightweight TCP protocol.

02

Workers run inference

Independent nodes execute the same task locally using Ollama — real LLM output, not simulated.

03

Network verifies consensus

The coordinator compares responses. Majority agreement defines correctness. Outliers are flagged.

04

Fast workers earn MLC

Nodes matching consensus receive token rewards. Faster responses earn a larger share of the pool.
